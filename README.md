# ytm2spotify

Move your YouTube Music library (albums, subscribed artists, liked songs) to Spotify — and review every match side by side before anything is saved.

> **Discontinued (2026-10-13).** v0.0.1 works, but it offers no real advantage over existing services such as TuneMyMusic — see [ADR-006](docs/adr/006-stop-project.md) and the [retrospective](docs/RETROSPECTIVE.md) (Korean).
