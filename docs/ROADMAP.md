## 다음 세션 (오늘 밤 22:43 Spotify 검색 할당량 리셋 전에)

| # | 작업 | 이유 |
|---|---|---|
| 1 | **자동 재개 (방식 A)**: 앱이 켜져 있으면 할당량 리셋 시각까지 기다렸다가 매칭을 이어감. 앱 시작 시 리셋이 지났으면 바로 재개 | 좋아요 1,034곡에 검색 900~1,000회 필요 → 하루 약 540회 한도로 2~3일 걸림 (R6). 매일 수동 실행은 비현실적 |
| 2 | **매칭 화면**: 진행률, 할당량 상태, "다음 매칭: 22:43 (n시간 남음)" 카운트다운, 끝나면 데스크톱 알림 | 지금은 터미널에서만 보임. 멈춘 건지 고장 난 건지 알 수 없음 |
| 3 | **검색 절약**: 이미 매칭된 앨범의 수록곡과 로컬 비교(검색 없이 약 155곡) | 할당량 절약 |
| 4 | 나머지 좋아요 곡 매칭 → 검토 → 저장 (본인) | 실사용 마무리 |

결정: 자동 재개는 **A(앱 실행 중 대기 후 재개)**로 한다. B(OS 예약 작업: launchd/작업 스케줄러)는 불편하다는 피드백이 있을 때 v0.2에서 검토한다.
