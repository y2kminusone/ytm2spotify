# ADR-003: 처음부터 한국어/영어 두 언어를 지원한다

- 상태: Accepted
- 날짜: 2026-10-12

## 맥락

주 사용자는 한국어 사용자지만, GitHub로 공개하는 도구라 외국인도 쓸 수 있다. 화면 문구를 코드에 직접 써 두면 나중에 번역을 넣을 때 모든 화면을 다시 뜯어야 한다.

## 결정

- 지원 언어는 **한국어(원본)와 영어** 두 개로 시작한다.
- 앱 문구는 `i18n` 모듈 한 곳에 언어별 메시지로 모은다. 숫자나 문법이 들어가는 문구는 **함수**로 만들어, 언어마다 복수형(영어)이나 조사(한국어: '이라/라')를 직접 처리한다. 문자열을 이어 붙이지 않는다.
- 매칭 엔진의 판단 근거는 **언어 중립 코드**(`title_match`, `length_diff` + 값 등)로 저장하고, 화면에서 번역한다. → DB에 언어별 문장이 들어가지 않는다.
- Astryx 컴포넌트 내부 문구는 `InternationalizationProvider`와 Astryx가 제공하는 `ko-KR` 카탈로그로 처리한다.
- 언어 선택 순서: URL `?lang=` → 사용자가 고른 값(localStorage) → 브라우저 언어(`ko*`면 한국어, 아니면 영어).

## 결과

- (+) 새 문구를 추가할 때 두 언어를 동시에 쓰게 되어 번역 누락이 줄어든다(TypeScript 타입으로 키 누락 검출).
- (+) 언어를 추가할 때 메시지 파일 하나만 추가하면 된다.
- (−) 문구를 추가할 때마다 영어도 써야 한다.
- 매칭 로직의 한국어 특화 처리(한글/로마자 별칭, 공백 무시)는 언어 설정과 무관하게 항상 동작한다.
